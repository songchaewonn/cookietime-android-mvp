# CookieTime Android MVP

웹 화면을 WebView로 실행하고 Android 전용 동작은 JavaScript bridge와 네이티브 서비스에 연결한 독립 Android 프로젝트입니다. 웹 화면 원본은 이 저장소의 `web/` 폴더에 포함되어 있어 이 프로젝트만으로 빌드할 수 있습니다. 웹 저장소에서 화면을 바꾸면 동일 파일을 `web/`에도 반영해 주세요.

## Android Studio에서 열기

1. Android Studio를 설치하고 저장소 루트(이 폴더)를 프로젝트로 엽니다.
2. Android SDK Platform 35와 JDK 17 이상을 설치합니다.
3. Gradle 동기화가 끝나면 USB 디버깅을 켠 Android 기기에서 `app` 구성을 실행합니다.
4. 설정 화면에서 앱 사용 기록, 다른 앱 위 표시, 알림 권한을 허용합니다. 정확한 알람은 Android 설정에서 허용할 수 있고, 거부되어도 시스템이 허용하는 부정확한 알림으로 동작합니다.

## 연결된 기능

- 집중 시간과 쉬는 시간을 별도 누적하며, 쉬는 동안 집중 타이머는 멈춥니다.
- 첫 실행에 사용 기록·오버레이·알림·정확한 알람 권한을 안내하고, 설정에서 허용 상태를 확인할 수 있습니다.
- 할 일 항목에서 수정·삭제·메모 추가를 할 수 있습니다.
- 설치된 런처 앱 목록을 선택 목록으로 표시하고, 선택값을 패키지 이름으로 Android에 저장합니다.
- 금지 앱 감지 기준을 집중 세션 중, 항상, 특정 요일·시간으로 설정할 수 있습니다. 상시/예약 모드는 권한을 허용하면 Android foreground service를 시작합니다.
- 집중 시작 시 사용 기록 접근 권한과 오버레이 권한을 확인한 뒤 foreground service를 시작합니다.
- UsageStats 이벤트를 약 1.2초 간격으로 확인합니다. 선택된 앱이 화면에 올라오면 원본 쿠키 이미지를 포함한 플로팅 바를 띄우고, 복귀 시 닫습니다.
- 이탈 진동 임계값과 강도를 설정에서 바꿀 수 있습니다. 방해금지 모드 설정을 따르거나 진동을 시도하도록 선택할 수 있으며, 최종 동작은 Android 기기 정책에 따릅니다.
- 설정한 시작 예고 시점과 정각, 과제 마감 1일 전·3시간 전을 AlarmManager에 예약합니다. 정각 알림에서 집중 시작 또는 5분 미루기를 선택할 수 있고, 미루기는 최대 2회입니다.
- 시간표의 공강 기준과 할 일 정렬 기준은 웹 설정에 저장되고 Android 앱에서도 같은 화면으로 사용할 수 있습니다.
- 캐릭터 원본 이미지는 웹 프로토타입과 Android 오버레이가 같은 파일을 사용합니다.

## 현재 환경의 제한

현재 작업 환경에는 Android SDK와 Android Studio가 없어 APK를 여기서 빌드하지 못했습니다. 소스는 Android Studio에서 빌드할 수 있는 형태이며, 실제 알림·앱 감지·오버레이는 Android 버전과 제조사별 실기기 검증이 필요합니다. Play Store 배포 전에는 특수 사용 foreground service와 사용 기록 권한 정책도 검토해야 합니다.
